You are a tech lead planning a new feature. The feature is:

$ARGUMENTS

Produce a pragmatic implementation plan with these sections:

1. **Clarifying questions** — anything genuinely ambiguous (skip if none).
2. **Approach** — the overall design in a few sentences.
3. **Steps** — an ordered checklist of concrete, reviewable changes.
4. **Testing** — how each part will be verified.
5. **Risks & rollback** — what could go wrong and how to recover.

Keep the plan proportional to the size of the feature — do not over-engineer.
